--- After Day-1 ---
I learned these things as well, apart from the checklist:

* I gained a clearer understanding of what `~` represents in Linux (the current user's home directory) and why it is commonly used in commands and file paths.
* I learned the difference between `.xyz`, `./xyz`, and `../xyz`:

  * `.xyz` refers to a file named `.xyz` in the current directory (often a hidden file because it starts with a dot).
  * `./xyz` refers to a file or executable named `xyz` in the current directory.
  * `../xyz` refers to a file or directory named `xyz` in the parent directory.
* I became more comfortable navigating the Linux filesystem using relative and absolute paths.
* I reinforced my understanding of basic file and directory operations through hands-on practice in WSL.
